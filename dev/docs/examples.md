# Examples

[Overview](../README.md) · [Getting started](getting-started.md) · [Configuration](configuration.md) · [Providers](providers.md)

Open the [expandable examples in the root README](../README.md#examples) to see Fast Verify findings for every supported language family, Project Sense findings, and native compiler diagnostics. Each example includes its rule and evidence.

Follow [Getting started](getting-started.md) to try the examples in a disposable Git project. Native checks also require the setup and explicit execution authorization described in [Providers](providers.md).

Run `opcore rules` to see every built-in rule and its default policy field.
