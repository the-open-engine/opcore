1//! Fast source verification, dependency feedback, and four ASP check providers.
2//!
3//! Start with the [`api`] module for the supported application entrypoints and the
4//! [`api::ProviderProfile`] reference for Fast Verify, Rust-native, Node-native,
5//! and Python-native. The executable exposes these through `check`, `sense`,
6//! `run`, `doctor`, `status`, `rules`, `manifest`, and `serve --stdio`.
7//!
8//! The default checks parse an immutable Git view without executing repository code.
9//! Native providers are explicitly selected and require trusted code or an external sandbox.
10//! Implementation modules are private; this package is distributed as an executable.
